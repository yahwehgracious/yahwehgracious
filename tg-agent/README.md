# ШІ-таргетолог

Персональний таргетолог для власної реклами в Instagram/Facebook. Усе керування — у Telegram Mini App,
щоденна й щотижнева робота — на GitHub Actions. Сервер не потрібен.

## Що він робить

### Застосунок (Telegram Mini App, `tg-app/index.html`)
Говорить з Meta API напряму з телефона. Ключі Meta й ШІ зберігаються лише в Telegram CloudStorage.

| Вкладка | Що там |
|---|---|
| **Головне** | Ціна результату за 7 днів проти норми, відхилені Meta оголошення з причиною, рішення таргетолога (вимкнути / додати бюджет / замінити креатив) з кнопкою виконання, клієнти з реклами (дзвінки, оплати, CAC, ROAS), «Спитати ШІ-таргетолога» |
| **Реклама** | Кампанії з цілями: переписки в Direct, заявки через форму, переходи в Telegram, переходи на сайт. Для кожної групи: бюджет (кнопки або своя сума), аудиторія (міста, радіус, вік, стать або Advantage+), плейсменти (авто або IG стрічка/сторіс/Reels, FB стрічка), пауза. Ретаргет на тих, хто взаємодіяв з Instagram. Заявки з лід-форми з кнопкою дзвінка. Креативи: фото/відео 4:5 + вертикальна 9:16, до 3 текстів A/B/C, запуск у будь-яку кампанію, зміна тексту запущеного оголошення, причини відхилення й посилання на оскарження |
| **Звіт** | 7 днів / 30 днів / цей / минулий місяць, фільтр за кампанією, графік по днях, розбивка за віком, статтю, плейсментами, рейтинг оголошень |
| **Ідеї** | Сценарії для зйомки (щотижня + «згенерувати ще» з урахуванням твоєї статистики) і конкуренти: рекламодавці з оголошеннями, що крутяться 2+ тижні, з розбором ШІ |
| **⚙** | Ключ Meta, ключ ШІ (Anthropic або Gemini), таблиця клієнтів, посилання за замовчуванням, норми |

**Норми** рахуються з юніт-економіки: середній чек × частка на рекламу = скільки можна віддати за клієнта;
× конверсія переписки/заявки/переходу в клієнта = норма ціни результату. Зберігаються в CloudStorage
і міткою `ai_norms …` у кабінеті Meta, щоб щоранковий звіт брав ті самі.

**ШІ:** Opus 5.5 — ідеї, «Спитати таргетолога», перевірка норм; Sonnet 5.5 — тексти, розбір креативу, переписування.
У всі запити вшиті правила таргетолога (навчання, пороги вимкнення, +20% бюджету раз на 3 дні, малий бюджет, втома креативу, правила Meta).

### Щоранку 07:47 (GitHub Actions, `python -m targetolog daily ivan`)
Повідомлення в Telegram: вчора й 7 днів, ціна результату проти норми, відхилені оголошення, рішення.
Нічого в кабінеті не змінює.

### Щопонеділка 06:13 (`python -m targetolog update ivan --out ../tg-app/index.html --notify`)
1. Скрапить публічну бібліотеку реклами Meta (Playwright) за `search_terms` і `competitor_page_ids`. Якщо не вийшло — бере останні збережені дані.
2. Відсіює чуже: лишає тільки свою нішу (`relevance_rx`), прибирає курси, CRM-сервіси, демо (`exclude_rx`), дублі текстів.
3. Скоринг: дні в показі, кількість копій, перезапуски, пережиті оновлення.
4. Розбір ШІ (Sonnet, відео — Gemini) з кешем у `data.sqlite`; якщо Anthropic не відповідає — Gemini.
5. 6 нових сценаріїв (Opus).
6. Перебудовує застосунок, комітить, пише в Telegram, яким ШІ зроблено розбір.
Ручний запуск `update` з GitHub одразу генерує нові ідеї.

### Правила рішень (однакові в застосунку й звіті)
- Оголошення молодші 72 год не чіпаємо.
- Вимкнути: витрачено ≥ 2 норми без результату, або ≥ 3 результати по ціні > 1,5 норми. Єдине в групі — пропонуємо заміну.
- Частота > 3,2 — пора новий креатив.
- +20% бюджету: ≥ 5 результатів по ціні ≤ норми, не частіше ніж раз на 3 дні.

## Як запустити з нуля

### 1. Meta
1. business.facebook.com → створи застосунок (тип Business) і системного користувача з роллю Admin.
2. Признач йому рекламний кабінет, сторінку Facebook (повний доступ) і застосунок.
3. Згенеруй токен системного користувача з дозволами `ads_management`, `ads_read`, `business_management`,
   `pages_show_list`, `pages_read_engagement`, `pages_manage_ads`, `leads_retrieval`, `instagram_basic`; термін «Ніколи».
4. Прив'яжи карту в Meta (оплата лише там).
5. ID кабінету, сторінки (Graph ID) та Instagram — у `clients/ivan/client.json`.

### 2. Telegram
1. @BotFather → бот → токен. Menu Button → URL застосунку: `https://<github-user>.github.io/<repo>/tg-app/`.
2. Свій chat_id — у `client.json` → `telegram.chat_id`.

### 3. GitHub
1. Репозиторій із GitHub Pages (Settings → Pages → гілка `main`). Структура:
   ```
   .github/workflows/targetolog.yml
   tg-agent/            ← цей код
   tg-app/index.html    ← збирається автоматично
   tg-app/privacy.html  ← політика для лід-форм
   ```
2. Settings → Secrets and variables → Actions:
   `META_ACCESS_TOKEN`, `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY` та/або `GEMINI_API_KEY`.
3. Actions → targetolog → Run workflow → `update`, потім `daily`.

### 4. Застосунок
Відкрий бота → кнопка меню → ⚙: встав ключ Meta, ключ ШІ, посилання на таблицю клієнтів
(Google Таблиця з колонками «Дата», «Статус» — Дзвінок/Оплата, «Сума»; доступ «Усі, хто має посилання → Читач»), задай норми.

## Налаштування `clients/ivan/client.json`
| Поле | Що |
|---|---|
| `name`, `niche`, `product` | хто ти і що продаєш — на цьому ШІ пише тексти й ідеї |
| `kpi` | стандартні норми, поки не задав свої в застосунку |
| `search_terms`, `competitor_page_ids` | де шукати конкурентів |
| `relevance_rx`, `exclude_rx` | фільтр «своя ніша» / «не конкурент» |
| `scoring` | мін. днів у показі (14), скільки оголошень брати (24) |
| `analysis`, `brief` | провайдер ШІ (anthropic, запасний gemini) |
| `meta` | ID кабінету, версія API |
| `launch` | сторінка, Instagram, бюджет за замовчуванням, посилання, політика конфіденційності |
| `telegram` | chat_id, URL застосунку |

Моделі можна змінити змінними: `ANTHROPIC_MODEL` (за замовчуванням `claude-sonnet-5-5`),
`ANTHROPIC_MODEL_HEAVY` (`claude-opus-5-5`), `GEMINI_MODEL` (`gemini-flash-latest`).

```

  pipeline.py   щотижневе оновлення
  daily.py      щоранковий звіт і правила
  miniapp.py    увесь застосунок (HTML/CSS/JS) + збірка даних

  scoring.py    відбір конкурентів

  brief.py      генерація сценаріїв

  telegram.py   надсилання повідомлень
  db.py, util.py
clients/ivan/   конфіг, кеш (data.sqlite), запасні дані конкурентів

```

## Локально
```
pip install -r requirements.txt && python -m playwright install chromium
cp .env.example .env    # ключі
python -m targetolog update ivan --skip-collect
python -m targetolog daily ivan --no-send
```

## Безпека
- Ключі ніколи не потрапляють у репозиторій: на GitHub — у Secrets, у застосунку — в Telegram CloudStorage.
- Репозиторій публічний: видно ID кабінету й сторінки, але без токена з ними нічого не зробити.
- Без твого підтвердження застосунок нічого не змінює в кабінеті; щоранковий звіт лише читає.
